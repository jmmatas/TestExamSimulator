Introducción

El simulador CIS-DF Exam Simulator permite preparar la certificación ServiceNow Certified Implementation Specialist – CMDB Data Foundations.

Toda la información del progreso se almacena únicamente en el navegador (LocalStorage). No se envía información a Internet.

Pantalla principal

Desde esta pantalla se configura el examen.

  • Número de preguntas.
  • Modo de examen.
  • Orden de las preguntas.
  • Filtros.

Exam Setup

Questions

Número de preguntas que contendrá el examen.

Mode

Permite seleccionar el modo de funcionamiento.

Smart Order

Prioriza preguntas nunca vistas, preguntas débiles y preguntas marcadas.

Modos de examen

Certification

Simula el examen oficial.

Practice

Muestra inmediatamente si la respuesta es correcta.

Weak Questions

Entrena únicamente las preguntas con menor porcentaje de acierto.

Unseen Questions

Muestra preguntas que todavía no han sido respondidas.

Durante el examen

Durante el examen se muestra:

  • Número de pregunta.
  • Categoría.
  • Temporizador.
  • Barra de progreso.
  • Botón Marcar.

Review

Tras finalizar el examen se muestra una revisión completa de todas las preguntas.

Histórico

El histórico muestra el rendimiento obtenido para cada pregunta.

Utilice los filtros por Dominio para localizar rápidamente las áreas con menor porcentaje de acierto.

Estadísticas

  • Seen
  • Accuracy
  • Completed Exams
  • Average repetitions

FAQ

¿Cómo reinicio las estadísticas?

Utilice el botón Reset Statistics.

¿Dónde se guardan los datos?

En el LocalStorage del navegador.
